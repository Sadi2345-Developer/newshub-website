# NewsHub - Real-Time Global News Portal

**NewsHub** is a modern, responsive, and dynamic news application built with **React.js**. It integrates the **NewsData.io API** to fetch and display real-time breaking news from global sources. The project is designed with a focus on security, clean UI architecture, and seamless API integration.

## Features

* **Live News Feed:** Fetches the latest global headlines dynamically.
* **Professional Dark UI:** Built using **Bootstrap 5** with a sleek, dark-themed aesthetic.
* **Dynamic Component Mapping:** Uses React's `map()` function to render news results into reusable card components.
* **State Management:** Implements `useState` and `useEffect` hooks for managing API data and loading states.
* **Robust Error Handling:** Includes custom logic to display error states and loading spinners for a smooth UX.
* **Secure API Implementation:** Utilizes **Environment Variables** (`.env`) to protect sensitive API keys.
* **Fully Responsive:** Optimized using Bootstrap's grid system for mobile, tablet, and desktop views.

## Tech Stack

* **Frontend Library:** React.js (Vite)
* **Styling:** Bootstrap 5 & Custom CSS
* **API:** NewsData.io (Fetch API with Async/Await)
* **Icons:** Bootstrap Icons
* **Deployment:** Firebase Hosting

## Project Structure

The landing page is organized into several high-conversion sections:
* **Interactive Navbar:** Branding and smooth navigation links.
* **Hero Section:** High-impact call-to-action with animated typography.
* **Headlines Grid:** The core feature where news cards are rendered dynamically.
* **About Section:** A professional overview of the platform's vision.
* **Contact System:** A modern, styled contact form for user engagement.
* **Newsletter Subscription:** Integration-ready footer for user retention.
